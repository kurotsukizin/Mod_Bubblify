# 💬 Bubblify - Immersive Chat Bubbles

Bubblify transforms how players communicate in Minecraft. Originally designed to enhance immersion and facilitate roleplay (RP) on survival servers, this mod takes players' eyes off the bottom left corner of the screen and brings their focus back to the world around them.



Whenever a player types something in the chat, the message appears in a stylish floating “speech bubble” directly above their head, making group conversations, camp events, and town interactions much more organic and visual.

## ✨ Key Features


Dynamic Speech Bubbles: Messages float smoothly above players, following their movement. Perfect for quickly identifying who is speaking in a crowd.



RGB Color Picker: Every player is unique! Bubblify features a modern and intuitive graphical user interface (GUI) where players can use sliders (Red, Green, Blue) to create and preview the exact color of their text in real time.



Text Color Selection: Contrast matters! Alongside the RGB background picker, players can easily toggle between Black or White text using the dedicated side panel, ensuring messages are always crisp and readable regardless of their chosen bubble color.



Smart Memory (Client-Side Saving): Thanks to an optimized configuration system, the color chosen by the player is saved locally on their computer. You can close the game and come back the next day: your chat color will remain exactly as you left it!





### ⊰══════════⊱



## 🎭 Focus on Roleplay and Immersion


If you run a server focused on narrative development, communities, or survival in hostile worlds, Bubblify is essential. It adds a deep visual layer to social interactions, eliminating the confusion of standard Vanilla chat.



### ⊰══════════⊱



## 🛠️ Server Admin Control



For server owners who want to push immersion to the maximum, Bubblify offers a built-in custom command system. Admins with permission level 2 or higher can use the command:

/bubblify show_chat false

This completely hides the standard Vanilla chat on the bottom left corner for all players! Communication becomes strictly visual and local through the floating bubbles, completely changing the dynamic of the server. (Can be easily reverted at any time using true).

## ⚙️ Compatibility and Installation


Required: Requires the mod to be installed on both the Client side (to render the bubbles and color panel) and the Server side (to synchronize network packets between players).
